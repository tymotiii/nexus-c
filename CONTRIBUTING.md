# Contributing to Nexus-C

Thanks for contributing.

## 🧾 Rules

- Keep code simple
- No unnecessary abstractions
- No external dependencies
- Stick to C

## 📂 Code Style

- Be consistent
- Keep functions small
- Comment non-obvious code

## 🛠️ How to Contribute

1. Fork repo
2. Create branch:

```bash
git checkout -b feature/your-feature
```

3. Make changes
4. Test with:

```bash
make run
```

5. Commit:

```bash
git commit -m "Add: description"
```

6. Open PR

## 🧪 Testing

- Must boot
- Must not crash

## 💡 What to Work On

- Bug fixes
- Features
- Cleanup
- Docs

## 🚫 Don't

- Rewrite everything
- Add bloat
- Add dependencies

## 📬 Questions

Open an issue
